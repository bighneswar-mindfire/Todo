Write what the next session needs into `session-context.md` (repo root, git-ignored). The `PreCompact` hook already refreshes the auto snapshot (branch, git state, active change, last handoff block, last `review.md` section, next tasks) before every compaction; this command adds the part only this session knows.

1. **Refresh the snapshot**: run `node .claude/hooks/save-context.mjs`. Then read `session-context.md`. If the file is missing it was not created: say so and stop.
2. **Write the notes**: replace everything between `<!-- notes:start -->` and `<!-- notes:end -->` with the text below, using Edit. Touch nothing outside those markers; the auto block is regenerated by the hook.

   ```
   ## Notes (<YYYY-MM-DD HH:MM>)
   - Doing: <the one thing in progress, in a sentence>
   - Done this session: <bullets: decisions made and why, files changed>
   - Next: <the exact next command or step, for example `/opsx:apply ab-1042` or "wait for the human's commit of task 2.3">
   - Waiting on: <the human's commit, an answer to an open decision, Docker down, or "nothing">
   - Open questions: <one line each, with the recommendation, or "none">
   - Do not redo: <things already checked or ruled out>
   ```

3. **Rules for the notes**: facts and decisions only, a screenful at most. Paths, commands, IDs and statuses; no secrets, tokens, `.env` values, request bodies or pasted ticket text. State what is true now, not what you intend to do later. Do not copy what the auto block already holds (branch, tasks, handoff).
4. **Finish**: print the notes and say: "Saved. Run `/clear`, then start the next session with: read `session-context.md` and continue." Do not run `/clear` or `/compact` yourself.

Resuming: in the new session read `session-context.md`, then the change's `handoff.md` (the state machine decides what may run next). The notes are a hint, the handoff and `git log` are the truth; if they disagree, trust them and say so.
